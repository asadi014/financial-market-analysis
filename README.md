# Iranian Stock Market — Weekly Data Analysis

## Overview

This project presents a data-driven analysis of the Iranian stock market
(Theran Stock Exchange) for a selected weekly period.

The objective is to analyze market performance, trading activity, sector
behavior, and key market indicators, and to extract meaningful insights
from the available data.

## Objectives

- Analyze weekly market performance
- Evaluate major market indicators
- Compare industry and sector performance
- Analyze trading volume and value
- Identify significant market trends
- Generate data-driven insights

## Analysis Workflow

The analysis follows a structured data analytics workflow:

1. Data Collection
2. Data Preparation and Cleaning
3. Exploratory Data Analysis (EDA)
4. KPI Analysis
5. Data Visualization
6. Insight Generation

## Tools & Technologies

- Microsoft Excel
- Power BI
- Data Analysis
- Data Visualization

## Key Analysis Areas

- Market Index Performance
- Industry Performance
- Trading Volume
- Trading Value
- Market Breadth
- Weekly Returns
- Market Trends

## Data Source

The analysis is based on publicly available financial market data.
